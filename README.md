# ERMS

Sistema do escritório Rafael de Mello Souza (processos, prazos, conversas, leads, honorários e relatórios), instalável no computador e no celular.

Este repositório contém **somente o programa**. Nenhum dado de cliente fica aqui: os dados ficam exclusivamente na conta Dropbox do usuário (pasta Aplicativos), acessada após login com o Dropbox.

App: https://rafaadvogado.github.io/erms/
